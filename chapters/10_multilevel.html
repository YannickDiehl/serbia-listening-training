10. Multilevel models

NoteAbout this chapter

The preregistered test of the training effects: one multilevel model per outcome with the interaction of wave and condition, questionnaires nested in persons nested in municipalities, and the same models with the trainers as a further level. Two further models replicate the effect when the control group trains, random slopes ask whether the change differs between trainers, municipalities and persons, also within each condition, and equivalence tests check the claims that the groups do not differ at baseline and after both trainings. One-sided tests and a correction for testing many outcomes show how much the counts of significant effects depend on these choices. Feeds the preregistered results of Hypotheses 1 to 3.

source("R/packages.R")                  # all packages (Chapter 1)
source("R/settings.R")                  # waves, conditions, folders (Chapter 1)

df_wide <- readRDS("cache/df_wide.rds") # one row per person (Chapter 2)

The outcomes are the 23 scale scores and the three hypothesis composites (Chapter 2). Two small helpers fit a model for any outcome and return its fixed effects with Satterthwaite degrees of freedom (lmerTest):

composites <- c("H1_ListeningTogetherness", "H2_CognitiveComplexity",
                "H3_Wellbeing")
outcomes   <- c(scales$scale, composites)

# readable names of the outcomes, for the text
composite_labels <- c(H1_ListeningTogetherness = "Listening and Togetherness",
                      H2_CognitiveComplexity   = "Cognitive Complexity",
                      H3_Wellbeing             = "Well-being")
label_of <- \(outcome) {
  coalesce(scales$label[match(outcome, scales$scale)],
           unname(composite_labels[outcome]))
}

# a multilevel model of one outcome: "outcome ~ " and the right-hand side
# (further arguments, such as the optimizer, go to lmer())
mlm <- \(outcome, rhs, data = df, REML = TRUE, ...) {
  lmer(as.formula(str_c(outcome, " ~ ", rhs)), data = data, REML = REML, ...)
}

# the fixed effects of a model, with Satterthwaite df and p
fixed <- \(fit) {
  tidy(fit, effects = "fixed") |>
    select(term, b = estimate, se = std.error, df, p = p.value)
}

10.5 Random slopes

Does the change differ between trainers and municipalities? Helmert contrasts code time (T0 against later waves; T3 against earlier waves, Chapter 2). A model with random slopes of both contrasts at the trainer and municipality levels is compared with random intercepts only, by a likelihood-ratio test on maximum-likelihood fits:

slopes <- tibble(outcome = composites) |>
  mutate(intercepts = map(outcome, \(o) mlm(o,
           "TF_helmert + TS_helmert + (1 | trainedBy/Municipality) + (1 | id)",
           REML = FALSE)),
         slopes = map(outcome, \(o) mlm(o,
           "TF_helmert + TS_helmert +
            (TF_helmert + TS_helmert | trainedBy/Municipality) + (1 | id)",
           REML = FALSE)),
         test = map2(intercepts, slopes, \(a, b) anova(a, b)[2, ])) |>
  select(outcome, test) |>
  unnest(test) |>
  select(outcome, chisq = Chisq, df = Df, p = `Pr(>Chisq)`)

slopes |>
  mutate(across(where(is.double), \(x) round(x, 3)))

None of the three composites shows significant slope variance across trainers and municipalities. Condition varies between municipalities and is not in these models, so slope variance at the municipality level would partly express the training effect itself rather than differences between trainers.

Does the change vary within each condition? Within one condition every municipality had the same schedule, so slope variance there is free of the training effect. For all 26 outcomes and each condition separately, four likelihood-ratio tests on maximum-likelihood fits:

  • random slopes of both contrasts across municipalities, against random intercepts. Within one condition each trainer worked in exactly one municipality, so trainers and municipalities are the same ten groups and one level stands for both;
  • a random slope across persons, for each contrast on its own: both at once would need more random effects than there are questionnaires;
  • a fixed interaction of municipality and pre/post in the arm’s own training window (T0 to T1 in the experimental group, T2 to T3 in the control group): do the ten municipalities gain differently from their training?

Slope variances near zero make single optimizers stop at different points, so every model is fitted with three and the best fit is kept. The 208 tests take more than a minute and run as a script:

# Random slopes within each condition (Chapter 10.5): for the 23 scales and
# the three composites, in each condition separately, whether the change
# varies between municipalities and between persons, and whether the
# municipalities change differently in their own training window.
# Likelihood-ratio tests on maximum-likelihood fits (about 1.5 minutes).
# Run from swt-website/ after Chapter 2:  Rscript scripts/slopes_within.R

source("R/packages.R")
source("R/settings.R")
df <- readRDS("cache/df.rds")      # one row per questionnaire (Chapter 2)
item_names <- names(select(df, ListenOther1:CompetenceNonFrustrated4))
source("R/scales.R")               # the 23 scales (Chapter 2)

outcomes <- c(scales$scale, "H1_ListeningTogetherness",
              "H2_CognitiveComplexity", "H3_Wellbeing")
time     <- "TF_helmert + TS_helmert"   # the two time contrasts (Chapter 2)

# each arm's own training window: T0 to T1 (experimental), T2 to T3 (control)
training_window <- list(Experimental = c("T0", "T1"),
                        Control      = c("T2", "T3"))

# a maximum-likelihood fit with three optimizers, keeping the best: with slope
# variances near zero, single optimizers stop at different points
ml_fit <- \(formula, data) {
  fits <- map(c("bobyqa", "Nelder_Mead", "nloptwrap"), \(optimizer)
    suppressWarnings(suppressMessages(
      lmer(as.formula(formula), data = data, REML = FALSE,
           control = lmerControl(optimizer = optimizer)))))
  fits[[which.max(map_dbl(fits, logLik))]]
}

# likelihood-ratio test of a model against the same model with more terms
lr_test <- \(data, outcome, base, extended) {
  m0 <- ml_fit(str_c(outcome, " ~ ", base), data)
  m1 <- ml_fit(str_c(outcome, " ~ ", extended), data)
  chisq <- max(2 * (as.numeric(logLik(m1)) - as.numeric(logLik(m0))), 0)

}

10.6 Equivalence tests

Do the groups really not differ? Two claims of the preregistration are claims of absence: the groups do not differ at baseline (condition at T0), and they no longer differ after both have trained (condition × T3). A non-significant test does not show absence; two one-sided tests (TOST) do, against a smallest effect of interest of Δd = ±0.20. Each coefficient of the preregistered models (10.2) is divided by the standard deviation of the outcome at T0. Equivalence holds when the 90 % confidence interval lies within ±0.20.

sesoi <- .20

# the TOST of one coefficient, in units of the SD at T0
tost <- \(fit, term, sd_T0) {
  fixed(fit) |>
    filter(term == .env$term) |>
    transmute(term,
              delta_d = b / sd_T0,
              se_d    = se / sd_T0,
              ci_low  = delta_d - qt(.95, df) * se_d,
              ci_high = delta_d + qt(.95, df) * se_d,
              p_tost  = pmax(pt((delta_d + sesoi) / se_d, df,
                                lower.tail = FALSE),
                             pt((delta_d - sesoi) / se_d, df)),
              p_two_sided = p)
}

# the verdict of the TOST, next to the two-sided test
verdict_of <- \(p_tost, p_two_sided) case_when(
  p_tost < .05 & p_two_sided >= .05 ~ "equivalent",
  p_tost < .05                      ~ "different but trivially small",
  p_two_sided < .05                 ~ "different",
  .default                          = "inconclusive"
)

# both claims for the models in `fit`, in units of the SD at T0
claims <- \(models) {
  models |>
    mutate(sd_T0 = map_dbl(outcome, \(o) sd(df[[o]][df$Occasion == "T0"],
                                            na.rm = TRUE))) |>
    mutate(after_both = pmap(list(fit, "OccasionT3:conditionExperimental",
                                  sd_T0), tost),
           baseline   = pmap(list(fit, "conditionExperimental", sd_T0),
                             tost)) |>
    select(-c(fit, sd_T0)) |>
    pivot_longer(c(after_both, baseline), names_to = "claim",
                 values_to = "test") |>
    unnest(test) |>
    mutate(verdict = verdict_of(p_tost, p_two_sided))
}

10.7 One-sided tests and many outcomes

Does the result hold if the tests are one-sided? The hypotheses are directional. The experimental group should gain more by T1 and keep its advantage at T2 (positive interactions, 10.2); the control group should gain more while it trains (negative terms in the period-specific model and in the second term of the piecewise model, 10.3), while the first piecewise term should be positive. A one-sided test looks only in the expected direction: it halves the p of an effect that points there and gives an effect against the expectation a p above .5. The tests above stay two-sided.

# the directional tests of 10.2 and 10.3, with the sign they expect
directional <- bind_rows(
  interactions |>
    filter(wave %in% c("T1", "T2")) |>
    transmute(test = str_c("preregistered, ", wave), outcome, b, se, df, p,
              expected = 1),
  period_specific |>
    transmute(test = "period-specific, T3", outcome, b, se, df, p,
              expected = -1),
  piecewise |>
    transmute(test = str_c("piecewise, ", training, " training"), outcome,
              b, se, df, p,
              expected = if_else(training == "experimental", 1, -1))
) |>
  mutate(p_one_sided = pt(expected * b / se, df, lower.tail = FALSE))
