# Listening Skills Training in Serbia

Analysis documentation of a waitlist-controlled field experiment: a listening
skills training for social workers in 20 Serbian municipalities, measured at
four waves (January to December). The documentation shows every analysis with
its code and results.

Website: https://yannickdiehl.github.io/serbia-listening-training/

This repository holds the rendered website only. It contains no raw data and
no participant codes.
